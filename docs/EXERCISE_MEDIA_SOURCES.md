# Exercise media: source, rights, and review

The expanded local batch maps 100 existing Wellframe IDs to RepDB's official free-tier stills. Source index: https://exercise-dataset.com/exercises.json. License: https://github.com/RepDB/exercise-dataset/blob/main/LICENSE-DATA.md. The import was rechecked on 19 October 2026. Index SHA-256: `947fbf730c805b66f4ff2de4341ff1a82fca8e9937b22fa98109440ba2ac1300`. The publisher permits commercial in-app use with visible attribution, but not republishing the media as a dataset or using it for generative-AI derivations. Paid-tier animation previews were not imported.

Visible attribution is in You → About → Media credits and each covered exercise detail. The importer records the provider ID, original index, creator, license URL, retrieval date, changes, actual dimensions and byte sizes in `public/data/exercise-media.json` and `public/data/media-credits.json`. The app uses local `/media/exercises/<canonical-id>/...` URLs, not remote image hotlinks. Run `.venv/bin/pip install Pillow`, then `.venv/bin/python tools/import_exercise_media.py --dry-run` and `.venv/bin/python tools/import_exercise_media.py` to reproduce the batch. Recheck the live license before any future import or commercial release.

One hundred IDs have thumbnails, 92 have two poses, and 270 have no exact imported still. Unmatched exercises display original, clearly labeled catalog artwork rather than an unrelated pose. The UI calls sourced poses illustrations, not demonstrations, and the positions are not evidence of a movement path. External qualified technique review is pending. Do not turn on coaching claims, copy unreviewed form instructions, or treat these as certified biomechanics. The exact still mapping and missing IDs are enumerated in `EXERCISE_MEDIA_COVERAGE.md`.

Four canonical exercise IDs now have click-to-load YouTube form previews, representing three unique NASM videos: [flat barbell bench press](https://www.youtube.com/watch?v=CayG6UYqL8g), [barbell Romanian deadlift](https://www.youtube.com/watch?v=xgusDooVfKU), and [forearm front plank](https://www.youtube.com/watch?v=xhk1JkbF2lg). `public/data/exercise-videos.json` records the exact IDs, title, publisher and variation. This is a title/publisher/variation match, **not** an independent clinical or coaching review. The two duplicate Romanian-deadlift entries share one clip. All other exercises link to a clearly labeled, unreviewed YouTube search. The app uses the privacy-enhanced YouTube embed only after an explicit tap; no video files are downloaded, preloaded or stored by the service worker. YouTube can still collect data on playback; an original-video link is available if an embed fails. Recheck availability, embed permission, variation, and form quality before expanding coverage or release.

The service worker precaches only three popular thumbnails; it keeps at most 32 additional WebP assets and never preloads video. Native apps do not yet consume this manifest. No Commons GIF or third-party motion clip has been imported because variant matching, per-file licensing, technique review, and codec/device validation remain open.
